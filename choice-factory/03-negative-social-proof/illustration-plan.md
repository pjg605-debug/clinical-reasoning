# 《선택하는 인간》 제3편 · 그림 설계표 v1

> 원고: 2026-10-20 검증 본문 (13절·52문단). 상태: 그림 시안 생성 가능 / 사용자 검수 대기. 공개 HTML 삽입 금지.

## 고정 미술 방향
- 제2편에서 사용자가 승인한 둥근 동물 캐릭터, 따뜻한 파스텔 수채화, 부드러운 종이 텍스처, 귀여운 표정과 짧은 대사를 유지한다. 기존 IP의 구체적 캐릭터를 복제하지 않는다.
- 16컷 전체 시트는 검수용이다. 최종 원고에는 **개별 고해상도 도해**를 모바일에서 읽을 수 있도록 분산 배치한다.
- 이미지 생성 텍스트는 임시 시안이다. 도표의 정확한 수치/한글은 텍스트로 검수하여 후속 편집한다. 원서 수치 및 측정 단위는 엄격하게 검증한다.
- 원고 검증은 완료됐지만 **사용자 승인 전에는 그림을 GitHub Pages에 올리지 않는다.**

## 공개 게이트
- 그림 원본 확인 → 텍스트 및 숫자 수정 → 각 컷 승인/수정/제외 → 웹용 개별 파일 생성 → 승인된 그림만 해당 원고 절 중간/끝에 삽입 → Pages 배포 및 각 src 응답 검증.
