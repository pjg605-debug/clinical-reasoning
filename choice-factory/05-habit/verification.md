# 제5편 Habit · 사용 주장과 확인 범위

확인일: 2026-10-21, Asia/Seoul. 원고: 「결심은 바뀌었는데 손은 왜 같은 곳으로 갈까」.

## 교정·제외 사항

- 원서의 일지 연구 소개와 원논문을 구별했다. 서로 다른 연구를 합쳐 하나의 실험으로 표시하거나 원서의 45%를 통합 결과로 사용하지 않았다.
- 저자 측 브랜드 변경 설문, 기업 캠페인 성과, 나이 끝자리 관련 수치, 간호 지원의 의료 효과는 독립 검증 범위 밖이라 결과 수치·효과 주장으로 사용하지 않았다.
- Verplanken & Roy (2016) 기관 저장소 PDF는 서지와 일부 서론만 읽힌 뒤 후속 접근이 시간 초과됐다. 이 논문의 실험 방법·결과를 검증한 것으로 표시하지 않으며 본문 근거로 사용하지 않았다.
- 종설에서 재인용한 모든 연구와 최신 문헌 전체를 확인하지 않았다. 사전 출판본과 출판사 최종 지면을 구별한다.
- 한의원 장면은 정보 전달과 직원 업무의 가상 예시다. 진료 효과, 환자 행동 개선, 특정 알림·기록 방법의 효과를 보장하지 않는다.

## 삽화와 주장 연결

- 05-05는 연구 1의 방법 도해다. 동물 인물과 독서/주말 계획 행은 설명용 창작이며 결과 수치를 그리지 않는다.
- 05-06은 일상 체감 예시다. 실제 연구 장치·참가자·반응 크기 재현이 아니다.
- 05-01·02·03·04는 가상 개념·생활·운영 사례다. 그림으로 효과를 입증하지 않는다.
- 05-02는 승인된 V3, 05-06은 사용자가 허용한 첫 두 버전 중 V1을 사용한다. 모든 공개 원본은 승인 장부의 SHA256과 일치해야 한다.

## 제작 확인과 남은 범위

원고·정식 문단 배치·검증 문서는 작성했다. 배포·공개 원본 해시·브라우저 검증은 별도 실행 보고서에 실제 결과로 기록한다. 이 문서만으로 게시 성공을 주장하지 않는다. 기존 제2·3편의 전면 검증이나 예약의 정기 실행 성공은 이번 작업의 범위가 아니다.
