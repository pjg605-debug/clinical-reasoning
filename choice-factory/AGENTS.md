# 《선택하는 인간》 집필·교정 기준

한국어 원고를 집필하거나 교정할 때 [명확한 한국어 설명문 스킬](editorial/korean-explicit-prose/SKILL.md)을 기본 편집 기준으로 읽고 적용한다. 로컬 개인 스킬 이름은 `korean-explicit-prose`다. 이 파일과 스킬은 문체 기준을 저장하며, 새 회차 제작·기존 본문 변경·배포를 자동 실행하라는 지시가 아니다.

사용자는 2026-10-21 제목 ‘행동을 수정하겠다고 마음먹은 뒤에도 손은 왜 습관대로 움직이는가’와 그 도입문을 예로 들어, 독자가 대상을 추측해야 하는 표현을 줄이고 현상과 설명 원리를 명시하도록 요청했다. 이후 ‘제1~5편 전체에 적용’이라고 명시해 이번 문체 교정에는 제1편도 포함했다. 다른 연재는 범위에 포함하지 않는다.

제목·도입에서 제시한 질문이 본문의 설명·연구·사례로 이어지는지 검토한다. 수치·연구 조건·출처·인용·불확실성·가상 표기를 보존하고, 문체 수정만으로 연구 검증 상태를 상향하지 않는다. 이미 명확한 문장과 이해를 돕는 구체적 사례·비유는 유지한다.

기존 문단 ID·순서·저장 키·독서 기능과 승인 삽화 원본을 보존한다. 본문이 바뀌면 기존 기록의 인용문을 확인해 표시한다. 일치하지 않거나 중복돼 위치를 확정하지 못하는 인용은 잘못된 본문에 표시하지 않고 보관함에 원문·메모를 유지한다. 동작 근거는 `tests/prose-anchors.test.cjs`와 `prose-anchors.js`다.

회차별 현재 원고는 같은 폴더의 `manuscript.md`다. 문체 교정 이전의 원고·게시 보고서는 당시 상태의 기록이며 현재 제목과 구별한다. 첫 게시용 생성 스크립트로 교정된 본문을 덮어쓰지 않는다. 새 그림은 내장 image_gen만 사용하고 개별 사용자 승인 뒤 게시한다.
